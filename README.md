# Лабораторная работа 1. Файлы и каталоги

Программа на C и shell-скрипт создают одинаковую структуру каталогов и файлов.

## Сборка

```sh
make
```

## Создание на C

```sh
./lab1 result
```

## Создание скриптом

```sh
./create.sh result
```

Перед запуском каталог `result` не должен существовать.

## Просмотр результата

```sh
ls -laR result
```

## Удаление

```sh
./remove result
```

## Структура

```text
result/
└── a/
    ├── b/
    │   └── cat.txt
    ├── c/
    │   └── dog.txt
    ├── d -> c
    └── e/
        ├── f.txt
        ├── g.bin
        └── h.bin
```

`cat.txt` содержит строку `catts`, `dog.txt` пустой. `d` — символьная ссылка на `c`, `f.txt` — жесткая ссылка на `b/cat.txt`. Размер `g.bin` — 500 байт случайных данных, размер `h.bin` — 35 нулевых байт.
